# 올림픽공원 공연·주차 길잡이 / Olympic Park Show & Parking Guide

올림픽공원 공연 일정을 표준화해 보여 주고, 공연일 시간대별 주차 혼잡 예보와 대중교통 대안을 안내하는 정적 웹서비스입니다. 한국체육산업개발(주) 개방 공공데이터를 바탕으로 만들었습니다.

## 기능
1. **공연 일정** : 공공데이터의 공연장 표기(119종)를 표준 공연장 10종으로 통일하고, 여러 날 공연을 날짜별로 풀어 보여 줍니다. 공연이 아닌 항목(대관 준비 자리표)은 자동으로 제외합니다. 회차별 시작 시각은 기관 누리집 상세 글의 "시간" 칸(자유 서술)을 읽어 날짜별 시각으로 표준화해 붙입니다.
2. **주차 혼잡 예보** : 요일·시각·대형 공연 시작 시각까지의 거리·비·월로 그 시간대 입차 대수와 수준(여유·보통·혼잡·매우 혼잡)을 예상하고, 공연장별 가까운 주차장·출입문·지하철을 함께 안내합니다. 공연 일정에서 넘어오면 시작 2시간 전 시각을 기본으로 잡습니다.
3. **데이터 점검판** : 자료를 받을 때 자동으로 걸러 낸 항목(표기 불일치·빈칸·중복)과 회차 시각 표기 오류(요일 불일치·기간 밖 날짜·요일 빈칸·'시' 누락)를 정정안과 함께 보여 줍니다.

## 사용 데이터
- 한국체육산업개발(주) 개방 공공데이터(공공데이터포털): 올림픽공원 공연정보, 올림픽공원 입출차 정보(2024년 7월), 월별주차현황, 주차장 혼잡도 정보, 영문 공연정보, 주차 안내
- 한국문화정보원 문화 공공데이터광장: 공연정보(통합) API_CCA_144
- 기상청: 단기예보, 지상(종관, ASOS) 시간자료 / 한국천문연구원: 특일 정보

## 구조
```
index.html, assets/        화면(정적, 외부 라이브러리 없음)
data/shows.json            공연 자료(매일 갱신)
data/quality.json          점검 결과(매일 갱신)
data/details.json          회차 시각·예매 링크(기관 누리집 상세 글, 매일 갱신)
data/titles_en.json        영문 제목·외국인용 예매처(기관 영문 게시판, 매일 갱신)
data/weather.json          기상청 단기예보 오늘부터 4일 뒤까지(올림픽공원 격자 62·126, 하루 2회 갱신)
data/model.json            혼잡 예보 모델 v1.2(기준값 72칸·공연 효과 5구간·비 효과·월 보정, 검증 수치 포함)
data/files_check.json      기관 개방 파일 2종(주차장 혼잡도·월별 주차현황) 점검 결과
data/source/               모델 추정용 원천 표(입출차 시간별 744행, 월별 주차현황, 혼잡도, 2024년 7월 누리집 일정)
data/venues.json           공연장별 주차장·출입문·지하철
data/holidays.json         공휴일(2024~2027, 한국천문연구원)
scripts/build_data.py      공연 자료 수집·표준화·점검
scripts/fetch_details.py   누리집 상세 글 수집·회차 시각 해석·표기 점검
scripts/fetch_titles_en.py 영문 게시판 수집·공연정보와 짝짓기(날짜·제목 낱말 겹침)
scripts/fetch_weather.py   기상청 단기예보 수집(비 입력 자동 채움)
scripts/build_model.py     혼잡 예보 모델 추정·하루씩 빼고 검증(numpy)
scripts/build_link_table.py 입출차 원자료(공공데이터포털 15138735)+ASOS+공휴일+공연 일정 → 시간별 연계표
scripts/check_files.py     개방 파일 2종 점검
.github/workflows/         매일 06:23·18:37(KST) 자료 갱신(공연 API 실패 시에도 날씨·회차는 갱신)
```

## 자료 갱신
```
KCISA_KEY=<문화공공데이터광장 서비스키> python3 scripts/build_data.py
python3 scripts/fetch_details.py
python3 scripts/fetch_titles_en.py        # 처음 한 번은 --full
KMA_KEY=<공공데이터포털 서비스키> python3 scripts/fetch_weather.py
```
GitHub Actions에서는 저장소 비밀값 `KCISA_KEY`·`KMA_KEY`를 씁니다. 누리집 상세 글은 다가오는 공연(120일 안)만 1초 간격으로 읽고, 읽지 못하면 지난 값을 유지합니다.

## 예보 모델
```
입차(시간당) = 기준[요일구분][시] × 공연효과[시작 시각까지 거리]^(대형공연) × 비효과^(비) × 월보정[월]
```
2024년 7월 입출차 744시간으로 로그 선형 최소제곱 추정. 하루씩 빼고 31회 재추정한 검증에서 평균 절대 오차 약 36대/시간, 4단계 수준 일치 약 81%(칸 평균 방식과 비슷한 정확도, 회차 시각을 입력으로 씀). 수준 경계(7월 50·75·90 백분위 331·445·551대)에는 예상 대수와 같은 월 보정을 곱하므로, 수준은 그 달 안에서의 상대 혼잡입니다. 자세한 수치는 `data/model.json`의 `validation`.

## 한계
- 예보 모델은 2024년 7월 한 달치 입출차로 추정했습니다(대형 공연일 8일). 2025년 입출차 API가 열리면 다시 추정합니다. 계절 차이는 월별 주차현황의 7월 대비 비율로만 반영합니다.
- 예약 실행(GitHub Actions)은 혼잡 시 지연되거나 건너뛸 수 있어 갱신 시각을 화면에 표시합니다.
- 회차별 시작 시각은 공공데이터에 없어 기관 누리집 상세 글의 자유 서술("토 오후 6시 / 일 오후 4시" 등 40여 가지 꼴)을 해석합니다. 해석하지 못한 글은 "시각 미확인"으로 표시하고 원문 링크로 안내합니다.
